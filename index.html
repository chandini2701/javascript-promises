1. What is a Promise?

A Promise is a JavaScript object that represents the eventual success or failure of an asynchronous operation. For example, a server request may take time to complete. 

const myPromise = new Promise((resolve, reject) => {
    resolve("Operation successful!");
});

myPromise.then(result => {
    console.log(result);
});

2. Why Do We Need Promises?

Some operations take time, such as fetching data from a server, reading a response or waiting for a timer. Promises help us handle their results without blocking the main JavaScript thread. 

console.log("Start");

setTimeout(() => {
    console.log("Operation completed");
}, 1000);

console.log("End");

// Output:
// Start
// End
// Operation completed

3. Promise States

Pending

The operation has not settled yet.

Fulfilled

The operation completed successfully.

Rejected

The operation failed.

A Promise starts pending and settles as fulfilled or rejected. Once settled, its state cannot change.

4. Promise Concepts

Creating a Promise

The Promise constructor accepts an executor function. JavaScript calls it immediately with resolve and reject. 

const task = new Promise((resolve, reject) => {
    const success = true;

    if (success) {
        resolve("Task completed");
    } else {
        reject("Task failed");
    }
});

resolve() and reject()

resolve fulfills a Promise with a value. reject rejects it with a reason, usually an Error object. 

const result = new Promise((resolve, reject) => {
    let marks = 80;

    if (marks >= 35) {
        resolve("Pass");
    } else {
        reject(new Error("Fail"));
    }
});

.then()

.then() registers handlers for fulfillment and optionally rejection. It returns a new Promise. 

Promise.resolve(10)
    .then(value => {
        return value * 2;
    })
    .then(result => {
        console.log(result); // 20
    });

.catch()

.catch() handles a rejection from the Promise chain. It can also recover by returning a normal value. 

Promise.reject(new Error("Something failed"))
    .catch(error => {
        console.log(error.message);
        return "Recovered";
    })
    .then(value => console.log(value));

.finally()

.finally() runs after the Promise settles, whether it fulfilled or rejected. It is useful for cleanup. 

Promise.resolve("Success")
    .finally(() => {
        console.log("Operation finished");
    })
    .then(value => console.log(value));

Promise Chaining

Return a value or another Promise from .then() to run asynchronous steps in sequence. 

Promise.resolve(5)
    .then(value => value + 5)
    .then(value => value * 2)
    .then(result => console.log(result)); // 20

Promise.resolve() and Promise.reject()

These static methods create fulfilled or rejected Promises. Promise.resolve also adopts a Promise or thenable passed to it. 

Promise.resolve("Hello")
    .then(value => console.log(value));

Promise.reject(new Error("Failed"))
    .catch(error => console.log(error.message));

Promise.all()

Fulfills when every input fulfills. Rejects as soon as an input rejects. Results preserve input order. 

Promise.all([
    Promise.resolve("HTML"),
    Promise.resolve("CSS"),
    Promise.resolve("JavaScript")
]).then(results => console.log(results));

Promise.allSettled()

Waits for all input Promises to settle and returns each outcome with its status. 

Promise.allSettled([
    Promise.resolve("Success"),
    Promise.reject(new Error("Failed"))
]).then(results => console.log(results));

Promise.race()

Settles with the outcome of the first input Promise that settles. 

Promise.race([
    new Promise(resolve =>
        setTimeout(() => resolve("First"), 500)
    ),
    new Promise(resolve =>
        setTimeout(() => resolve("Second"), 1000)
    )
]).then(result => console.log(result));

Promise.any()

Fulfills with the first fulfilled input. If all inputs reject, it rejects with an AggregateError. 

Promise.any([
    Promise.reject("Failed"),
    Promise.resolve("Success")
]).then(result => console.log(result));

Async and Await

An async function always returns a Promise. Await pauses that function until the Promise settles. 

function getData() {
    return Promise.resolve("Data received");
}

async function displayData() {
    const result = await getData();
    console.log(result);
}

displayData();

Error Handling with try...catch

Inside an async function, use try...catch to handle a rejected Promise awaited with await. 

async function loadData() {
    try {
        const result = await Promise.reject(
            new Error("Unable to load data")
        );
        console.log(result);
    } catch (error) {
        console.log(error.message);
    }
}

loadData();

Callback vs Promise

Callbacks pass a function to another function. Promises provide a standard way to represent an eventual result and chain asynchronous steps. 

// Callback
setTimeout(() => {
    console.log("Callback completed");
}, 500);

// Promise
Promise.resolve("Promise completed")
    .then(result => console.log(result));
